# 同舟健康 · 网站雏形（TongZhou Health Prototype）

> AI 驱动的病友互助与健康决策平台 —— 产品雏形（纯前端交互演示）

让求医路，不再孤单。该原型实现了产品文档中的五大模块，用于在开发 App 之前验证核心交互与产品逻辑。

## ✨ 功能模块

| 模块 | 说明 |
|---|---|
| 🫂 同舟圈 | 按病症分圈的病友社区：浏览/发布经验帖、共鸣（点赞）、评论、**AI 经验卡片**一键提炼长帖要点 |
| 🤝 病友匹配 | 同病症 · 同阶段 · 同城加权打分的病友匹配，打招呼连接同路人 |
| 📍 同舟就医通 | 医院口碑 / 费用区间参考 / **AI 核验**标注；药品价格、医保类别与替代方案对比 |
| 📋 我的档案 | 检查报告、用药清单、复诊提醒，**AI 生成病情摘要**辅助复诊沟通 |
| 💬 同舟智伴 | AI 病友管家：找病友、查医院、问药价、情绪陪伴（本地规则模拟） |
| 🛡️ 同舟守护 | 医学审核体系 / 隐私分级保护 / AI 自迭代闭环说明 |

## 🚀 运行

纯静态站点，无需构建：

```bash
# 方式一：直接双击 index.html
# 方式二：本地服务器
python -m http.server 8790
# 访问 http://127.0.0.1:8790/
```

首次访问会出现引导：选择病症圈 → 所处阶段 → 昵称，之后所有内容按你的情况个性化。

## 🛠 技术说明

- 原生 HTML / CSS / JavaScript，单页应用，无框架、无构建工具
- 演示数据内置于 `js/data.js`；用户数据（昵称、发帖、点赞、聊天记录等）仅保存在浏览器 `localStorage`，**不上传任何服务器**
- 「AI 能力」在雏形阶段由本地规则模拟，正式版规划接入大语言模型（LLM）、检索增强生成（RAG）、语义向量匹配、多模态报告识别、医学知识图谱与隐私计算
